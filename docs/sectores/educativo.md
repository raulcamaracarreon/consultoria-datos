# Sector educativo

Acompañamos a instituciones, áreas técnicas, escuelas, organismos y proyectos educativos que necesitan generar, ordenar, analizar y comunicar información para la mejora.

## Necesidades comunes

- Evaluar aprendizajes, prácticas, programas o servicios.
- Diseñar instrumentos confiables.
- Analizar resultados educativos.
- Construir indicadores de seguimiento.
- Sistematizar información de escuelas, docentes o estudiantes.
- Elaborar reportes técnicos y ejecutivos.
- Monitorear avances y brechas.
- Desarrollar tableros de consulta.

## Servicios recomendados

- Diseño de instrumentos.
- Evaluación docente.
- Evaluación institucional.
- Evaluación de programas educativos.
- Análisis psicométrico.
- Procesamiento de bases masivas.
- Construcción de indicadores.
- Dashboards educativos.
- Informes técnicos.
- Presentaciones ejecutivas.

## Productos posibles

- Cuestionarios.
- Rúbricas.
- Bancos de reactivos.
- Matrices de indicadores.
- Reportes de resultados.
- Tableros de seguimiento.
- Bases depuradas.
- Informes para toma de decisiones.
- Presentaciones para actores educativos.

## Resultado esperado

Las instituciones educativas cuentan con evidencia clara para comprender resultados, identificar brechas y orientar acciones de mejora.
