# Investigación de mercados

Diseñamos y analizamos estudios para comprender clientes, usuarios, consumidores, servicios, productos y experiencias.

## Necesidades comunes

- Conocer hábitos de consumo.
- Medir satisfacción.
- Evaluar percepción de servicio.
- Segmentar clientes.
- Identificar oportunidades de mejora.
- Analizar opiniones o preferencias.
- Diseñar encuestas y reportes claros.

## Servicios recomendados

- Diseño de encuestas.
- Estudios de opinión.
- Estudios de satisfacción.
- Estudios de hábitos de consumo.
- Segmentación de clientes.
- Análisis de preferencias.
- Procesamiento de bases.
- Reportes estadísticos.
- Presentaciones ejecutivas.

## Productos posibles

- Cuestionario.
- Base de datos.
- Reporte de resultados.
- Segmentación.
- Tablas y gráficas.
- Presentación ejecutiva.
- Recomendaciones comerciales.

## Resultado esperado

El cliente comprende mejor a sus usuarios o consumidores y puede tomar decisiones comerciales basadas en evidencia.
