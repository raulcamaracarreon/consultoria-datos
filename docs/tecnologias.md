# Tecnologías

La selección de herramientas depende del contexto, presupuesto, infraestructura, seguridad y necesidades del cliente.

## Captura y levantamiento

- LimeSurvey.
- Google Forms.
- Microsoft Forms.
- Formularios personalizados.
- Hojas de cálculo con validaciones.
- Plataformas internas del cliente.

## Limpieza y procesamiento

- Excel avanzado.
- Power Query.
- Python.
- Pandas.
- NumPy.
- SQL.
- R.
- SPSS.

## Análisis

- Python.
- R.
- SPSS.
- SQL.
- Bibliotecas estadísticas.
- Herramientas de ciencia de datos.
- Modelos de machine learning, cuando aplique.

## Visualización

- Power BI.
- Looker Studio.
- Python.
- Matplotlib.
- Plotly.
- Streamlit.
- Flask.
- Dashboards personalizados.

## Automatización y desarrollo

- Python.
- SQL.
- Power Query.
- n8n.
- Flask.
- PySide6.
- Aplicaciones internas de escritorio o web.
- Integraciones mediante APIs, cuando aplique.

## Criterios para seleccionar herramientas

- Necesidad real del cliente.
- Facilidad de mantenimiento.
- Costo de licencias.
- Seguridad de la información.
- Capacidad del equipo usuario.
- Escalabilidad.
- Posibilidad de automatización.
- Compatibilidad con sistemas existentes.

## Principio general

La herramienta debe adaptarse al problema, no el problema a la herramienta.
