# Limpieza, ETL y sistematización de datos

Antes de analizar, visualizar o automatizar información, es necesario contar con bases limpias, integradas y documentadas.

Esta línea se enfoca en transformar datos dispersos o inconsistentes en bases confiables y listas para análisis.

## Qué resolvemos

- Bases con duplicados.
- Datos faltantes.
- Formatos inconsistentes.
- Catálogos desordenados.
- Archivos separados que deberían integrarse.
- Bases difíciles de cruzar.
- Procesos manuales propensos a error.
- Falta de diccionarios de datos.

## Servicios

- Limpieza de bases de datos.
- Homologación de formatos.
- Normalización de catálogos.
- Tratamiento de valores faltantes.
- Detección de duplicados.
- Detección de valores atípicos.
- Integración de bases de distintas fuentes.
- Procesos ETL: extracción, transformación y carga.
- Preparación de bases para análisis estadístico.
- Preparación de bases para dashboards.
- Documentación de reglas de transformación.

## Herramientas posibles

- Excel avanzado.
- Power Query.
- SQL.
- Python.
- Pandas.
- R.
- SPSS.

## Entregables

- Base limpia.
- Base integrada.
- Diccionario de datos.
- Catálogos normalizados.
- Scripts de procesamiento.
- Bitácora de limpieza.
- Procedimiento replicable.
- Reporte de calidad de datos.

## Resultado esperado

El cliente obtiene bases confiables, ordenadas y documentadas para análisis, reportes, tableros o procesos automatizados.
