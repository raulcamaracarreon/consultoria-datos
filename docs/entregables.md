# Entregables

Los entregables dependen del alcance del proyecto, las necesidades del cliente y la modalidad de contratación.

## Entregables metodológicos

- Diagnóstico de información.
- Diseño metodológico.
- Matriz de variables.
- Matriz de indicadores.
- Modelo de evaluación.
- Línea base.
- Documento metodológico.
- Manual de aplicación.
- Criterios de valoración.

## Entregables de datos

- Base de datos limpia.
- Base integrada.
- Diccionario de datos.
- Catálogos normalizados.
- Bitácora de transformación.
- Scripts de procesamiento.
- Reporte de calidad de datos.
- Procedimiento replicable.

## Entregables analíticos

- Reporte estadístico.
- Tablas y gráficas interpretadas.
- Tabulares masivos.
- Indicadores.
- Índices.
- Segmentaciones.
- Modelos explicativos.
- Modelos predictivos, cuando aplique.
- Reporte psicométrico.

## Entregables visuales y tecnológicos

- Dashboard ejecutivo.
- Dashboard operativo.
- Reporteador interactivo.
- Aplicación interna.
- Sistema de consulta.
- Flujo automatizado.
- Manual de uso.
- Documentación técnica.

## Entregables ejecutivos

- Informe técnico.
- Resumen ejecutivo.
- Presentación en PowerPoint.
- Infografía.
- Fichas de resultados.
- Recomendaciones accionables.
- Paquete de gráficas y tablas.
- Guion de presentación.

## Resultado esperado

Cada entregable debe ser claro, útil, revisable y orientado a la toma de decisiones.
