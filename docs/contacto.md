# Contacto

Podemos iniciar con una reunión breve para conocer las necesidades de información de la organización y definir una ruta de trabajo.

## Solicita una reunión

En la primera conversación revisamos:

- Qué problema se busca resolver.
- Qué información existe actualmente.
- Qué decisiones se quieren apoyar.
- Qué productos se requieren.
- Qué plazos y restricciones existen.
- Qué nivel de acompañamiento conviene.

## Información útil para iniciar

Para preparar una propuesta específica, es conveniente contar con:

- Objetivo general del proyecto.
- Ejemplos de bases de datos.
- Ejemplos de reportes actuales.
- Instrumentos existentes, si aplica.
- Usuarios finales de la información.
- Frecuencia de actualización esperada.
- Formato deseado de entrega.
- Restricciones de confidencialidad o seguridad.
