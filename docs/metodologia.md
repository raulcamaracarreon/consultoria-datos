# Metodología de trabajo

La consultoría puede desarrollarse en fases, de acuerdo con las necesidades, presupuesto y nivel de madurez de información del cliente.

## Fase 1. Comprensión del problema

Se realiza una reunión inicial para conocer los objetivos del cliente, sus necesidades de información, los datos disponibles, los usuarios finales y las decisiones que se busca apoyar.

### Productos de esta fase

- Minuta de necesidades.
- Definición del problema.
- Preguntas de análisis.
- Alcance preliminar.

## Fase 2. Diagnóstico de información

Se revisan las fuentes de datos, instrumentos, bases, reportes, procesos de captura y criterios existentes.

### Productos de esta fase

- Diagnóstico de información.
- Inventario de fuentes.
- Identificación de problemas de calidad.
- Recomendaciones iniciales.

## Fase 3. Diseño metodológico y técnico

Se define cómo se obtendrá, procesará, analizará y presentará la información.

### Productos de esta fase

- Plan de trabajo.
- Diseño de instrumentos, si aplica.
- Diseño de indicadores.
- Diseño de estructura de bases.
- Definición de herramientas.
- Cronograma.

## Fase 4. Procesamiento, análisis y desarrollo

Se ejecutan las actividades principales: levantamiento, limpieza, integración, análisis, automatización, desarrollo de tableros o elaboración de reportes.

### Productos de esta fase

- Bases limpias.
- Scripts.
- Tableros.
- Análisis estadísticos.
- Indicadores.
- Reportes preliminares.

## Fase 5. Validación con el cliente

Se revisan resultados, criterios, visualizaciones, indicadores y hallazgos con el cliente para asegurar que los productos respondan a sus necesidades.

### Productos de esta fase

- Versión revisada de productos.
- Ajustes metodológicos o visuales.
- Validación de criterios.
- Registro de observaciones.

## Fase 6. Entrega final y transferencia

Se entregan productos finales, documentación, manuales y, cuando aplique, capacitación para uso de tableros, bases, sistemas o reportes.

### Productos de esta fase

- Entregables finales.
- Manuales.
- Documentación técnica.
- Capacitación.
- Recomendaciones de seguimiento.

## Modalidades de trabajo

=== "Proyecto específico"

    Para necesidades puntuales como una encuesta, un dashboard, una limpieza de base o un reporte.

=== "Implementación por fases"

    Para organizaciones que requieren ordenar gradualmente su ecosistema de información.

=== "Acompañamiento mensual"

    Para soporte recurrente en reportes, indicadores, dashboards o análisis.

=== "Solución personalizada"

    Para desarrollar herramientas internas, reporteadores, scripts o aplicaciones específicas.
