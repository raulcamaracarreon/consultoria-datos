# Casos de uso

Estos ejemplos muestran cómo pueden aplicarse los servicios de consultoría en situaciones concretas.

## Caso 1. Diagnóstico y limpieza de bases

### Necesidad

El cliente tiene múltiples archivos con información duplicada, incompleta o inconsistente.

### Solución

Se revisan fuentes, se limpian bases, se homologan catálogos y se documentan reglas de transformación.

### Productos

- Base limpia.
- Diccionario de datos.
- Reporte de calidad.
- Recomendaciones de captura.

---

## Caso 2. Encuesta de satisfacción y reporte ejecutivo

### Necesidad

El cliente quiere conocer la percepción de usuarios, clientes, estudiantes, docentes o beneficiarios.

### Solución

Se diseña el instrumento, se implementa el levantamiento, se procesa la base y se generan resultados.

### Productos

- Cuestionario.
- Base de datos.
- Reporte estadístico.
- Presentación ejecutiva.
- Recomendaciones.

---

## Caso 3. Dashboard de indicadores

### Necesidad

El cliente genera reportes manuales y necesita consultar información de forma dinámica.

### Solución

Se integran datos, se diseñan indicadores y se construye un tablero interactivo.

### Productos

- Dashboard.
- Manual de uso.
- Diccionario de indicadores.
- Capacitación.

---

## Caso 4. Evaluación de programa o servicio

### Necesidad

El cliente necesita saber si un programa, proyecto o servicio está funcionando.

### Solución

Se diseña un modelo de evaluación, se definen indicadores, se analiza información disponible y se generan hallazgos.

### Productos

- Modelo de evaluación.
- Matriz de indicadores.
- Informe de resultados.
- Recomendaciones de mejora.

---

## Caso 5. Automatización de reportes

### Necesidad

El cliente invierte muchas horas en reportes repetitivos.

### Solución

Se diseña un flujo automatizado para procesar datos y generar reportes periódicos.

### Productos

- Script o aplicación.
- Reportes automáticos.
- Manual de operación.
- Documentación técnica.

---

## Caso 6. Análisis psicométrico de instrumento

### Necesidad

El cliente cuenta con un cuestionario, prueba o escala y necesita revisar su calidad técnica.

### Solución

Se analiza la estructura del instrumento, la consistencia de sus dimensiones, el comportamiento de reactivos y la confiabilidad.

### Productos

- Reporte psicométrico.
- Recomendaciones de ajuste.
- Base analizada.
- Documento metodológico.
